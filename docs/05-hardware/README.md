# Hardware

SoC selection, block diagram, pad map and bring-up notes for the SoM and carrier. Schematics and layout are kept in a private repo; this folder holds what can be shared.

- [soc-selection.md](soc-selection.md) - SoC decision (STM32MP257), ST reference designs, candidates, prices, pad budget and design notes
- [som-pad-map.md](som-pad-map.md) - Draft 1 of the SoM to carrier pad map: 160 pads, signal groups, EV1 balls and open decisions
- [ev1-reference-block-diagram.md](ev1-reference-block-diagram.md) - Block diagram, buses and power tree of ST's EV1 reference board, built from its netlist
- [hw-framework/hw-docs-standard.md](hw-framework/hw-docs-standard.md) - The standard the hardware docs follow
